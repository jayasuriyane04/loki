Meridian API reference

Creating invoices

Send POST /v2/invoices with the customer id, line items and currency. Every create request must carry an Idempotency-Key header; a repeated key within 24 hours returns the original invoice instead of creating a second one.

Rate limits

Each API key may make 600 requests per minute. Requests over the limit get HTTP 429 with a Retry-After header in seconds.

Webhooks

Meridian sends invoice.paid and invoice.overdue events. Failed deliveries are retried 8 times with exponential backoff over roughly 24 hours. Every webhook carries an X-Meridian-Signature header: an HMAC-SHA256 of the raw body using your webhook secret.
